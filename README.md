# hello-world

男女对话格式记事本（单页面版）。

## 使用方式

1. 用 **浏览器** 打开 `index.html`（不要在 VS Code / 记事本里打开）。
2. 选择说话人（男生/女生），输入标题（可选）和对话内容。
3. 点击「添加对话」加入时间线。
4. 点击「保存到本地」将数据存到浏览器本地存储。
5. 点击「导出 TXT」可将当前内容导出为文本文件。
6. 点击「粘贴识别」，可批量粘贴对话并一键自动识别男女并追加到时间线。

> 小技巧：在输入框中按 `Ctrl + Enter`（Mac 上 `⌘ + Enter`）可快速添加对话。

## 粘贴识别示例

```text
男：今天开会顺利吗？
女：挺顺利的，下午就能出结果
男：太好了，那我等你消息
```

如果一行里没有明确的“男/女”标记，系统会按上一句的对方自动交替识别。

## 双击 `index.html` 打开成“代码”怎么办？

这通常是因为你的系统把 `.html` 默认关联到了代码编辑器。可用以下方式：

- Windows：双击运行 `start_notebook.bat`
- macOS / Linux：运行 `bash start_notebook.sh`
- 或者手动打开 Chrome/Edge/Safari 后，把 `index.html` 拖进去
