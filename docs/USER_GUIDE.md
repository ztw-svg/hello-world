# 用户使用说明

## 快速上手
1. 打开应用。
2. 在输入源区域选择本地文件/批量文件或输入链接。
3. 选择语言与输出格式。
4. 点击“开始提取”。
5. 完成后在编辑区校正并导出。

## 断点恢复
- 每个任务都会按片段写入 checkpoint。
- 异常退出后重试同一来源会跳过已完成片段。

## 自动保存
- 编辑区每 10 秒自动写入 `~/.transcriber_tool/drafts/`。

## 常见问题
- 提示 `ffmpeg` 不存在：请先安装 ffmpeg。
- URL 下载失败：升级 yt-dlp 或检查链接有效性。
- 云端模式失败：检查 API Key 与网络。
