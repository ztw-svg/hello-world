# 用户使用说明

## 快速上手
1. 打开应用。
2. 在输入源区域选择本地文件/批量文件或输入链接。
3. 点击“设置”，可开启说话人分离/男女标签并配置参数。
4. 点击“开始提取”。
5. 完成后在编辑区校正并导出。

## 角色区分与男女标签
- 说话人分离：为每段文本标记 `Speaker_x`。
- 男女标签（实验性）：基于音高估计，结果仅供参考。
- 若未配置 HF Token 或依赖缺失，会自动跳过角色分离。

## 断点恢复
- 每个任务都会按片段写入 checkpoint。
- 异常退出后重试同一来源会跳过已完成片段。

## 自动保存
- 编辑区每 10 秒自动写入 `~/.transcriber_tool/drafts/`。

## 常见问题
- 提示 `ffmpeg` 不存在：请先安装 ffmpeg。
- URL 下载失败：升级 yt-dlp 或检查链接有效性。
- 说话人分离失败：检查 HF Token、网络、pyannote 依赖。
