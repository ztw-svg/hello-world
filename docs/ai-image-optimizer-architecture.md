- 用户分层：
  - 普通用户：一键智能优化 + 风格预设。
  - 高级用户：参数细调 + 历史记录 + 批处理。
- 首版目标（MVP）：
  - 导入/导出主流格式（JPG/PNG/TIFF/WebP）。

  - 一键智能优化。
  - 5个基础预设。
  - 实时预览（低分辨率快速管线 + 全分辨率最终渲染）。

## 3. 核心模块设计

### 3.1 智能分析模块（Analyzer）

**输入**：原图（可选 EXIF）

**输出（JSON）**：

```json
{
  "image_type": "portrait|landscape|product|food|wedding|kids|id|old_photo",
  "lighting": {"type":"front|back|side|diffuse|artificial","cct":5200,"wb_shift":-0.12},
  "exposure": {"state":"under|normal|over","ev":-0.7,"dynamic_range":"low|mid|high"},
  "quality": {"noise":"low|mid|high","blur":"low|mid|high"},
  "mood": "warm|cool|lively|calm",
  "faces": [
    {"bbox":[x,y,w,h],"age_group":"adult","gender":"female","landmarks":"468pts"}
  ]
}
```

**建议模型/算法组合**：
- 图像分类：MobileNetV3 / EfficientNet-lite（按场景微调）。
- 人脸检测/关键点：RetinaFace + MediaPipe Face Mesh（MVP可先二选一）。
- 曝光/动态范围：统计直方图 + 局部对比度算法。
- 噪点评估：空域噪声估计 + 高频能量比。

### 3.2 策略决策引擎（Policy Engine）

根据分析结果自动产出处理图（DAG）：

- `portrait` → 皮肤处理 → 五官增强 → 色彩风格 → 输出锐化。
- `landscape` → HDR恢复 → 色彩增强 → 局部清晰度。
- `product` → 白平衡校正 → 几何/透视 → 锐化与背景清理。

策略应支持：
- 自动强度（Auto Strength）
- 用户覆盖（手工参数覆盖自动策略）
- 预设叠加（Preset + Auto混合）

### 3.3 人像精修引擎（Portrait Engine）

MVP先做“自然风格轻修”，高级能力分阶段接入：

1. 皮肤优化（非塑料感）
   - 频率分离（低频肤色统一 + 高频纹理保护）。
   - 瑕疵检测（小目标分割/检测）+ 局部修复。
2. 五官增强
   - 眼部提亮、牙齿美白、轻微法令纹与黑眼圈减淡。
3. 美型（第二阶段）
   - 基于关键点的受限形变场，增加“自然度约束”，避免肢体畸变。

### 3.4 场景增强引擎（Scene Engine）

- 智能HDR（亮部压缩 + 暗部提升 + 局部对比保护）。
- 天空替换（分割 + 边缘羽化 + 色温/光照一致性匹配）。
- 建筑透视矫正（检测线段求消失点）。

### 3.5 AI追色（Color Match）

三层策略：
1. 传统色彩统计匹配（直方图/LAB统计）
2. 光影分布匹配（分区曲线）
3. 深度风格迁移（可选，高耗时，非MVP默认）

## 4. 预设系统设计

预设文件建议 JSON：

```json
{
  "name":"奶油肌",
  "category":"portrait",
  "version":"1.0.0",
  "params":{
    "exposure":0.2,
    "contrast":-0.1,
    "skin_smooth":0.35,
    "skin_texture_preserve":0.8,
    "tone_temp":0.15,
    "sat":0.08
  }
}
```

MVP内置建议：质感肌、奶油肌、胶片感、清新、电商质感。

## 5. 批处理系统

- 队列模型：`pending/running/paused/done/failed`
- 并发策略：
  - CPU预处理并发
  - GPU推理串行或小批量（避免显存爆）
- 进度估算：按“已完成阶段权重”实时更新。

## 6. 性能与工程指标（可量化）

- 单张智能优化：1080p 下 ≤ 5 秒（中端GPU）。
- 预览响应：参数拖动到预览更新 ≤ 500ms。
- 内存峰值：常规流程 ≤ 4GB。
- 稳定性：连续处理 500 张无崩溃。

## 7. 数据与隐私

- 默认全离线；云API仅可选。
- 人脸/图像数据本地处理，本地缓存可一键清理。
- 崩溃日志脱敏（不记录原图像像素）。
