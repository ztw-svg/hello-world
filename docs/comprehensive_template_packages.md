# 全面预算填报模板包（多表版）

你提到“全面预算不应该只有一个表”，这是正确的。

之前的 `templates/budget_input_template.csv` 是**单表轻量版**，主要用于快速试跑脚本和做 PoC，适合收集：
- 利润表口径下的收入/成本/费用预算与实际
- 简单的组织、科目、产品、客户、项目维度
- 量价字段（qty/unit_price）

> 它不适合作为最终企业级“全面预算”唯一模板。

---

## 推荐的企业级模板包（本仓库已新增）

1. `templates/comprehensive/01_dim_mapping.csv`  
   组织+科目+报表口径+现金流标签映射（统一口径基础表）

2. `templates/comprehensive/02_budget_input_pl.csv`  
   利润表预算/实际（收入、成本、费用）

3. `templates/comprehensive/03_budget_input_bs.csv`  
   资产负债表预算/实际（期初、期末）

4. `templates/comprehensive/04_budget_input_cf.csv`  
   现金流量表预算/实际（经营/投资/筹资）

5. `templates/comprehensive/05_budget_input_eq.csv`  
   所有者权益变动表预算/实际（期初、变动、期末）

---

## 这些表各自收集什么

- **PL 表**：经营结果（收入、成本、费用）及量价驱动。
- **BS 表**：资产负债存量与营运资本变化。
- **CF 表**：现金收支结构与现金净增加额。
- **EQ 表**：资本投入、利润留存、分配导致的权益变动。
- **映射表**：保证四表能自动勾稽、可穿透追溯。

---

## 建议你怎么用

1. 先用 `01_dim_mapping.csv` 固定科目映射口径。
2. 每月收集 `02~05` 四张输入表。
3. 先做单体公司，再做合并口径。
4. 月结后跑自动图表/PPT，并用勾稽规则校验：
   - 总资产 = 总负债 + 所有者权益
   - 现金净增 = 期末现金 - 期初现金
   - 未分配利润期末 = 期初 + 本期净利润 - 分配
