# 月度预算执行分析PPT结构（管理层可直接套用）

## 封面
- 标题：`XX公司 月度预算执行分析`
- 副标题：`期间：YYYY-MM`
- 版本：`Budget Review vX.X`

## 目录页
1. 执行摘要
2. 四大报表总览
3. 收入分析
4. 成本分析
5. 费用分析
6. 现金流与营运资本
7. 风险与行动计划

## 1. 执行摘要（1页）
- KPI：收入、毛利、净利润、经营现金流、预算达成率
- 三条结论：本月亮点、主要偏差、下月风险

## 2. 四大报表总览（2页）
### 2.1 资产负债与权益
- 图：资产负债结构图（100%堆叠）
- 结论：资产负债率变化 + 驱动因素

### 2.2 利润与现金流
- 图：利润/现金流双轴趋势
- 结论：利润和现金流偏离的原因

## 3. 收入分析（2页）
- 图1：预算vs实际（收入）
- 图2：按产品/区域/客户结构
- 必答：价格、销量、结构三因素分解

## 4. 成本分析（2页）
- 图1：预算vs实际（成本）
- 图2：单位成本拆解（材料/人工/制造）
- 必答：采购价差、良率、产能利用率

## 5. 费用分析（2页）
- 图1：预算vs实际（费用）
- 图2：费用率趋势 + 成本中心排名
- 必答：刚性费用与弹性费用区分

## 6. 现金流与营运资本（1页）
- 图：应收、存货、应付与CCC趋势
- 必答：利润到现金流桥接

## 7. 风险与行动计划（1页）
- Top 5 偏差事项
- 每项写清：责任人 / 完成时间 / 量化目标
- 下月前瞻：高概率风险 + 预案

## 附录（可选）
- 勾稽检查结果清单
- 口径说明与科目映射
- 异常明细清单（按组织/客户/产品）
